## 🚁 Secure UAV Command & Control

A secure C++/Qt command-and-control platform for UAV systems.

The project combines **MAVLink telemetry, PostgreSQL,
Protobuf, Docker-based simulation, collision avoidance,
post-quantum cryptography, secure communication, blockchain
logging, and federated learning**.

Designed around UAV swarm simulations of up to **50 aircraft**.

```text
C++        Qt6          PostgreSQL
MAVLink    Protobuf     Docker
Linux      DTLS         ML-KEM / ML-DSA
```

The security layer explored technologies including
**ChaCha20-Poly1305, AES-256-GCM, DTLS, post-quantum cryptography,
and Byzantine-robust federated learning**.
